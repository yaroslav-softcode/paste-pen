✏️ Paste Pen  
Paste Pen — это не требующая установки, удобная программа для рисования поверх экрана Windows, вставки изображений и создания скриншотов. Отличный аналог Epic Pen, gInk с расширенным функционалом.

💡 Идея создания пришла ко мне когда в аналогичных программах меня не устроила реализация функции вставки картинки поверх рабочего стола и я решил устранить этот и другие недостатки при создании своего приложения.

🚀 Возможности  
Рисование левой и правой кнопкой мыши разным цветом.  
Инструменты: Ручка, Фигуры (Линия, Прямоугольник, Эллипс, Стрелка), Текст, Ластик.  
Выбор размера пера, линий, текста и ластика.  
Вставка изображений с возможностью перемещения и пропорционального растягивания.  
Инструмент Скриншот с захватом выделенной области вместе с рисунками.  
Поддержка работы на нескольких мониторах.  
Двуязычный интерфейс (Русский / English). Автоматическое сохранение языка при выходе.  
Сворачивающаяся анимированная панель инструментов с темной темой.  
Сохранение скриншотов в буфер обмена и открытие в настроенной системой программе.  
Приложение не требует установки.  

🖱️ Управление  
Одновременное нажатие ЛКМ + ПКМ: мгновенно включает режим Курсора.  
Левая и правая кнопка мыши: рисует разными цветами, когда выбран инструмент Ручка/Ластик/Фигуры.  
Чтобы выбрать цвет на правой или левой кнопке мыши нажмите соответствующеё кнопкой на кнопку Цвет.
Для выбора размера пера, линий, текста и ластика нажмите правой кнопкой на соответствующие кнопки. 
Для переноса вставленной картинки на передний/задний план нажмите на неё правой кнопкой мыши в режиме Выбор  
Для удаления вставленной картинки нажмите на неё правой кнопкой мыши в режиме Выбор

✏️ Paste Pen  
Paste Pen is a portable, user-friendly application for drawing over the Windows screen, inserting images, and taking screenshots. An excellent alternative to Epic Pen and gInk with extended functionality.

💡 The idea came to me when I was dissatisfied with how similar programs handled inserting images over the desktop, so I decided to fix this and other shortcomings by creating my own application.

🚀 Features
Drawing with the left and right mouse buttons using different colors.  
Tools: Pen, Shapes (Line, Rectangle, Ellipse, Arrow), Text, Eraser.  
Adjustable size for pen, lines, text, and eraser.  
Inserting images with the ability to move and proportionally resize them.  
Screenshot tool capturing the selected area along with your drawings.  
Multi-monitor support.  
Bilingual interface (Russian / English). The language is automatically saved on exit.  
Collapsible animated toolbar with a dark theme.  
Saving screenshots to the clipboard and opening them in the system's default image viewer.  
No installation required.  

🖱️ Controls
Simultaneous LMB + RMB press: instantly switches to Cursor mode.  
Left and right mouse buttons: draw with different colors when the Pen/Eraser/Shapes tool is selected.  
To select a color for the right or left mouse button, click the "Color" button with the respective mouse button.  
To choose the size of the pen, lines, text, or eraser, right-click the corresponding tool button.  
To bring an inserted image to the front or send it to the back, right-click it in the "Select" mode.  
To delete an inserted image, right-click it in the "Select" mode.
